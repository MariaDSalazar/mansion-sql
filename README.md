# La Mansión SQL

Repaso de Halloween sobre SQL Server: funciones de agregación y agrupación, manipulación de datos (DML) y transacciones y bloqueos.

## Cómo se usa

- Escriba sus nombres y sus apellidos y entre a la mansión.
- Hay tres salas, una por temática, con 10 preguntas cada una: opción múltiple, verdadero o falso y selección múltiple. Puede hacerlas en el orden que quiera.
- Si falla, vuelve a intentarlo; solo cuenta como acierto lo que resuelve al primer intento. Al acertar, ve por qué esa es la respuesta.
- Al superar las tres salas obtiene un certificado de culminación que se puede imprimir o descargar en PDF, desde el computador o el celular.
- Mientras hace el repaso no abra otras pestañas ni cambie de aplicación: si sale de la página, el repaso se bloquea y se reinicia.

Las preguntas, las opciones y las explicaciones viajan cifradas: cada pregunta se abre al resolver la anterior. El repaso no envía datos a ningún servidor.

## Cómo se corre

Es una página estática: abra `index.html` desde cualquier servidor de archivos (por ejemplo, GitHub Pages) en un navegador actualizado.
